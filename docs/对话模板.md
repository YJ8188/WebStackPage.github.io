## 📝 使用技巧

### 1. 提供充分的上下文

**❌ 不好的提问**
```
帮我优化代码
```

**✅ 好的提问**
```
【项目】何哥ERP
【文件】erp-ant.html 财务筛选部分
【问题】在移动端显示不对齐
【目标】优化响应式布局，确保 768px 以下正常显示

请分析问题并提供解决方案。
```

### 2. 分步骤请求

**❌ 不好的提问**
```
重构整个系统
```

**✅ 好的提问**
```
【阶段1】分析当前代码结构，识别可优化的模块
【阶段2】提供重构方案，优先处理核心模块
【阶段3】生成重构后的代码示例

请先完成阶段1的分析。
```

### 3. 明确约束条件

**❌ 不好的提问**
```
添加深色模式
```

**✅ 好的提问**
```
【功能】添加深色模式
【约束】
- 使用 CSS 变量实现
- 保持 Ant Design 风格
- 支持系统主题自动切换
- 保存用户偏好到 localStorage
- 不影响现有功能

请提供完整的实现方案。
```

### 4. 提供参考示例

**❌ 不好的提问**
```
优化表格性能
```

**✅ 好的提问**
```
【问题】财务表格加载 1000+ 条数据时卡顿
【期望】类似 Ant Design Table 的虚拟滚动效果
【参考】https://ant.design/components/table-cn/#components-table-demo-virtual-list
【技术栈】原生 JavaScript（不使用框架）

请提供性能优化方案。
```

## 🎯 实战示例

### 示例 1: 完整的功能开发流程

**第一步：需求分析**
```
【需求分析】数据导出功能

项目：何哥ERP
模块：财务管理

需求：
- 支持导出 Excel 和 CSV 格式
- 可以选择导出字段
- 支持导出当前筛选结果
- 显示导出进度

请分析技术方案。
```

**第二步：技术选型**
```
【技术选型】基于上次的分析

候选方案：
1. SheetJS (xlsx)
2. PapaParse (CSV)
3. ExcelJS

请对比这些方案，推荐最适合的。
```

**第三步：代码实现**
```
【代码实现】使用 [选定的方案]

请提供：
1. 完整的代码实现
2. 使用示例
3. 错误处理
4. 性能优化建议
```

**第四步：测试和优化**
```
【测试优化】数据导出功能

已实现基本功能，但发现：
- 导出大量数据时浏览器卡顿
- 某些特殊字符导出后乱码

请提供优化方案。
```
