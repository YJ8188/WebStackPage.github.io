# 🧭 何哥技术员网址导航

> 精选优质网站导航，为开发者和设计师打造的实用工具集合

## ✨ 特色功能

- 🎯 **精选网站** - 500+ 个高质量设计、开发、工具类网站
- ⭐ **收藏管理** - 自定义收藏夹，分类管理你的常用网站
- 🔍 **智能搜索** - 快速搜索，支持建议和历史记录

- 📱 **响应式设计** - 完美适配桌面、平板、手机
- 🔒 **安全认证** - 30天免登录，安全可靠
- ⚡ **性能优化** - 图片懒加载，WebP格式，极速访问

## 🚀 快速开始

### 本地开发

1. **克隆项目**
```bash
git clone https://github.com/hege/nav-website.git
cd nav-website
```

2. **安装依赖**
```bash
npm install
```

3. **启动开发服务器**
```bash
npm run dev
```

4. **访问网站**
打开浏览器访问 `http://localhost:3000`

### 生产部署

1. **构建项目**
```bash
npm run build
```

2. **部署到服务器**
将 `dist` 目录上传到你的服务器

## 🔧 功能模块详解

### 📢 通知系统
- 多种通知类型：成功、错误、警告、信息
- 自动关闭和手动关闭
- 进度条显示
- 支持回调函数

### ⭐ 收藏管理
- 分类管理：工作、生活、学习等
- 快速添加：Ctrl+D 快捷键

- 批量操作：批量删除、分类管理

### 🔍 搜索功能
- 智能建议：实时搜索建议
- 历史记录：保存搜索历史
- 快捷搜索：Ctrl+K 全局搜索
- 高级筛选：按分类、标签筛选

### 🌓 主题系统
- 浅色主题：适合白天使用
- 深色主题：护眼模式
- 自动切换：跟随系统设置
- 记忆功能：保存用户偏好

### 🔒 安全特性
- 30天免登录：安全Token机制
- 会话管理：自动超时保护
- 登录限制：防暴力破解
- 密码强度：实时安全检测

## 🎯 使用技巧

### ⌨️ 快捷键
- `Ctrl + K` - 打开全局搜索
- `Ctrl + D` - 添加当前页面到收藏
- `ESC` - 关闭弹窗/侧边栏

### 🔍 搜索技巧
- 使用关键词：`UI设计`、`React组件`
- 按分类筛选：点击左侧菜单分类
- 查看历史：搜索框下方显示历史记录

### ⭐ 收藏技巧
- 拖拽排序：在收藏页面拖动调整顺序
- 批量选择：Shift+点击多选
- 快速分类：收藏时选择对应分类
