## 🚀 快速开始

### 新手入门

1. **了解项目**
   - 阅读 `README.md` 了解项目基本信息
   - 访问 https://hq168.dpdns.org/erp-ant.html 体验系统

2. **配置开发环境**
   - 按照 `Claude-Code-配置指南.md` 配置 Claude Code
   - 运行 `setup-mcp.bat` 配置 MCP 服务器

3. **开始开发**
   - 使用 `对话模板.md` 中的模板与 Claude 对话

```
1. 打开 Claude Code
2. 使用对话模板开始新对话
3. 参考优化建议文档
4. 实施优化方案
5. 提交代码到 GitHub
```

## 💡 使用技巧

### 1. 善用文档引用

在与 Claude 对话时，可以这样引用文档：

```
请参考 docs/ERP-优化建议.md 中的性能优化部分，
帮我优化财务表格的加载性能。
```

### 2. 使用标准模板

使用 `对话模板.md` 中的模板可以：
- 提供完整的上下文
- 获得更准确的回答
- 节省沟通时间

### 3. 分阶段实施

参考 `ERP-优化建议.md` 中的实施路径：
- 短期（1-2周）
- 中期（1-2个月）
- 长期（3-6个月）

### 4. 持续迭代

每次对话都基于上次的结果：
```
【迭代优化】基于上次的实现

上次完成：✅ [功能]
本次改进：[改进点]

请提供改进方案。
```
