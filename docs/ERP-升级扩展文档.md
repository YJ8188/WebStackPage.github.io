# WebStack ERP 升级扩展文档（Agents + MCP）

## 1. 文档目标
- 用一套可执行方案，把当前 ERP 从“可用”升级到“稳定 + 可扩展 + 可持续迭代”。
- 引入“超级 Agents 协作 + MCP 工具链”，减少手工操作和重复排错成本。
- 提供可直接复制的提示词（Prompt）模板，后续你可直接复用。

## 2. 升级范围（建议分三期）

### 一期：稳定性与一致性（立即执行）
- 统一页面状态源：登录态、模块态、图表态只保留一套状态流。
- 修复关键链路容错：图表初始化、实时同步、模块切换、缓存刷新。
- 统一文案与样式：金额颜色、状态标签、空态提示、中文错误提示。
- 打通“订单→库存→财务”自动联动，保证新增/编辑/删除后的实时一致性。

### 二期：中级能力（业务增强）
- 财务分析增强：多维筛选、周期对比、净利趋势、异常波动提醒。
- 客户经营增强：客户画像、活跃度、复购周期、风险流失提醒。
- 库存策略增强：安全库存、补货建议、滞销识别、资金占用预警。
- 物流联动增强：订单状态自动回写、签收后自动更新交付状态。

### 三期：平台化（长期）
- 插件化模块：物流、财务报表、营销、审批等按模块扩展。
- 自动化质检：上线前自动执行语法检查、关键流程回归、风险扫描。
- 版本策略：灰度开关、回滚策略、数据修复脚本模板化。

## 3. 超级 Agents 协作模型（建议）
- `mission-control-orchestrator`：负责总体拆解、里程碑、风险跟踪。
- `js-ts-engineer`：负责前端 ERP 交互、状态流、图表、性能。
- `universal-review-guardian`：每轮改动后执行审查清单。
- `openai-docs`：当涉及 OpenAI 能力接入时，仅用官方文档校验。

协作顺序建议：
1) 编排 Agent 出任务清单  
2) JS Agent 落地改动  
3) Review Agent 回归审查  
4) 编排 Agent 生成下一轮计划  

## 4. MCP 集成建议（最小可用集合）
- `filesystem MCP`：读写项目文件、模板、配置。
- `git/github MCP`：分支校验、提交记录、推送状态反馈。
- `supabase MCP`：表结构核对、数据一致性检查、函数部署。
- `playwright MCP`：关键页面自动回归（登录、下单、财务联动、物流查询）。

目标：做到“改完即验、验完可追溯”。

## 6. 验收清单（每轮都要过）
- 登录后 3 秒内完成主界面可交互。
- 创建订单后，库存与财务流水实时刷新，不需手动刷新页面。
- 财务图表无控制台红错，切换模块无空白。
- 物流状态能自动推进订单状态。
- 游客与登录用户数据隔离（收藏、通知、主题配置不串号）。
- 控制台仅保留错误级日志（可读中文）。

## 7. 建议的推进节奏
- 每次只做一个“可闭环”主题（例如：图表稳定性）。
- 每轮结束必须产出：变更清单 + 验收结果 + 下一轮任务。
- 每 3~5 轮进行一次全链路回归（登录→下单→物流→财务）。

## 10. 升级扩展方案（详细）

### 10.1 一期：稳定性与一致性（1-2周）

#### 任务1：状态管理优化
**目标**：统一全局状态源，消除状态不一致问题

**具体任务**：
1. 重构 `ERP.state` 对象，建立单一数据源
2. 实现状态变更监听机制
3. 统一缓存策略（localStorage + 内存缓存）
4. 添加状态调试工具

**验收标准**：
- 模块切换无数据丢失
- 刷新页面状态恢复正常
- 控制台无状态相关错误

#### 任务2：数据联动修复
**目标**：确保订单、库存、财务三者实时同步

**具体任务**：
1. 订单创建/编辑后自动更新库存
2. 订单状态变更自动生成财务记录
3. 采购入库自动更新产品库存
4. 添加数据一致性校验

**验收标准**：
- 创建订单后库存立即减少
- 订单完成后财务记录自动生成
- 采购入库后产品库存立即增加
- 数据不一致时有明确提示

#### 任务3：错误处理增强
**目标**：提升系统容错能力和用户体验

**具体任务**：
1. 统一错误提示文案（中文化）
2. 添加网络请求重试机制
3. 实现降级策略（离线模式）
4. 优化加载状态展示

**验收标准**：
- 网络错误有友好提示
- 关键操作失败可重试
- 离线状态下可查看缓存数据
- 加载状态清晰可见

#### 任务4：UI一致性优化
**目标**：统一视觉风格和交互体验

**具体任务**：
1. 统一金额显示格式（千分位、小数位）
2. 统一状态标签颜色和文案
3. 统一表格行高和间距
4. 统一按钮样式和间距
5. 优化移动端适配

**验收标准**：
- 所有金额显示一致
- 状态标签颜色符合规范
- 表格布局整齐美观
- 移动端无遮挡和错位

### 10.2 二期：业务增强（2-3周）

#### 任务5：财务分析增强
**目标**：提供更强大的财务分析能力

**新增功能**：
1. 多维度筛选（时间、客户、产品、分类）
2. 周期对比（同比、环比）
3. 净利趋势图（日/周/月）
4. 异常波动提醒（金额突增/突降）
5. 现金流预测

**技术方案**：

- 添加日期范围选择器
- 实现数据聚合计算
- 添加异常检测算法

4. 流失风险提醒（超N天未下单）

**技术方案**：
- 实现 RFM 模型算法

- 实现安全库存动态计算

#### 任务8：物流联动增强
**目标**：实现物流状态自动化管理

**新增功能**：
1. 物流状态自动回写订单
2. 签收后自动完成订单
3. 异常物流自动提醒
4. 物流时效分析
